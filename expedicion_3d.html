Cómo generar datos

Desde la raíz del repositorio:
python -m robot_expedition train
python -m robot_expedition evaluate
python -m robot_expedition serve
python -m robot_expedition demo --viewer abre el visor nativo de MuJoCo.
Para verlo en vivo, deja serve en una terminal, activa «En vivo» y en otra ejecuta python -m robot_expedition train --live-delay 0.5.
